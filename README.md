바탕화면에 펫을 띄워 두고, 키보드·마우스 사용 패턴으로 스트레스를 살펴 "쉬어가기"를 권하는 복약·마음관리 Windows 프로그램입니다.

## 내려받기

### [⬇ 케어퐁 최신 버전 내려받기](https://github.com/asiae-girls-2026/carepong-releases/releases/latest) · Windows 10 · 11 (64비트)

- 위 버튼을 누르면 **최신 릴리스 페이지**가 열려요. 아래 **Assets** 에서 `CarePong-Setup-win-….exe` 를 눌러 받으세요.
- 받은 설치파일을 실행하면 자동으로 설치되고 바로 켜집니다. 처음 켜면 데이터 수집 안내와 이름 설정이 나와요.
- 처음 실행할 때 **"Windows의 PC 보호(SmartScreen)"** 창이 뜨면 **추가 정보 → 실행**을 누르세요. (서명 없는 설치파일이라 그래요)
- 새 버전이 나오면 앱이 알려줘요. **설정 → ℹ️ 서비스 버전** 에서 현재 버전 확인과 업데이트를 할 수 있어요.
